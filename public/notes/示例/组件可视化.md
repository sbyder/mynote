## ④ 参数交互面板

调整卷积核、步幅、填充和输出通道，下面的尺寸与 Shape 会实时更新。

{@body
  const [kernel, setKernel] = DIL.useState(3);
  const [stride, setStride] = DIL.useState(1);
  const [padding, setPadding] = DIL.useState(1);
  const [channels, setChannels] = DIL.useState(64);
  const inputSize = 32;
  const outputSize = Math.max(0, Math.floor((inputSize + 2 * padding - kernel) / stride) + 1);
  const reset = () => {
    setKernel(3);
    setStride(1);
    setPadding(1);
    setChannels(64);
  };
}
<card padding={3} gap={3}>
  <title size="lg">卷积层参数</title>
  <col gap={1}>
    <text weight={600}>Kernel Size</text>
    <segmented-control
      options={[{"label":"1×1","value":1},{"label":"3×3","value":3},{"label":"5×5","value":5},{"label":"7×7","value":7}]}
      value={kernel}
      onChange={setKernel}
    />
  </col>
  <col gap={1}>
    <text weight={600}>Stride · {stride}</text>
    <slider min={1} max={4} step={1} value={stride} onChange={setStride} aria-label="Stride"/>
  </col>
  <col gap={1}>
    <text weight={600}>Padding · {padding}</text>
    <slider min={0} max={4} step={1} value={padding} onChange={setPadding} aria-label="Padding"/>
  </col>
  <col gap={1}>
    <row justify="between" align="center">
      <text weight={600}>Output Channels</text>
      <title size="lg">{channels}</title>
    </row>
    <slider min={8} max={256} step={8} value={channels} onChange={setChannels} aria-label="Output Channels"/>
  </col>
  <divider/>
  <grid columns={2} gap={3}>
    <grid-item>
      <caption>输出空间尺寸</caption>
      <title size="2xl" color={outputSize > 0 ? "#20b66a" : "#d65b5b"}>{outputSize > 0 ? outputSize + " × " + outputSize : "无效"}</title>
    </grid-item>
    <grid-item>
      <caption>输出通道数</caption>
      <title size="2xl">{channels}</title>
    </grid-item>
  </grid>
  <card variant="filled" padding={3} gap={1}>
    <title size="md">最终输出 Shape</title>
    <title size="2xl">N × {channels} × {outputSize} × {outputSize}</title>
    <caption>采用 NCHW 格式，N 为输入批次大小。</caption>
  </card>
  <row justify="end">
    <button variant="outline" color="neutral" onClick={reset}>恢复默认参数</button>
  </row>
</card>

## ⑤ 定制可视化：神经网络结构

这种图可以直接用 SVG 绘制，也可以把节点和连线绑定到交互状态。点击不同层，观察对应节点高亮。

{@body
  const [activeLayer, setActiveLayer] = DIL.useState("hidden");
  const ys = [66, 126, 186, 246];
  const activeColor = "#18b987";
  const mutedColor = "#34404a";
  const layerColor = (name) => activeLayer === name
    ? (name === "input" ? "#4385ee" : name === "hidden" ? "#18b987" : "#a44de5")
    : "#52606b";
}
<card padding={3} gap={2}>
  <row align="center" justify="between" wrap>
    <title size="lg">神经网络示意</title>
    <badge color="success" label="动态视觉" />
  </row>
  <segmented-control
    options={[{"label":"输入层","value":"input"},{"label":"隐藏层","value":"hidden"},{"label":"输出层","value":"output"}]}
    value={activeLayer}
    onChange={setActiveLayer}
  />
  <svg viewBox="0 0 800 320" width="100%" role="img" aria-label="输入层、隐藏层和输出层组成的神经网络">
    {Array.from({length:4},(_,i) => Array.from({length:4},(_,j) =>
      <line key={"ih-"+i+"-"+j} x1={135} y1={ys[i]} x2={400} y2={ys[j]} stroke={activeLayer === "input" || activeLayer === "hidden" ? "#526b63" : mutedColor} stroke-width={2} opacity={0.72}/>
    ))}
    {Array.from({length:4},(_,i) => Array.from({length:4},(_,j) =>
      <line key={"ho-"+i+"-"+j} x1={400} y1={ys[i]} x2={665} y2={ys[j]} stroke={activeLayer === "hidden" || activeLayer === "output" ? "#526b63" : mutedColor} stroke-width={2} opacity={0.72}/>
    ))}
    {ys.map((y,i) => <circle key={"in-"+i} cx={110} cy={y} r={18} fill={layerColor("input")}/>)}
    {ys.map((y,i) => <circle key={"hid-"+i} cx={400} cy={y} r={18} fill={layerColor("hidden")}/>)}
    {ys.map((y,i) => <circle key={"out-"+i} cx={690} cy={y} r={18} fill={layerColor("output")}/>)}
    <text x={110} y={294} text-anchor="middle" fill="currentColor" font-size="22">输入层</text>
    <text x={400} y={294} text-anchor="middle" fill="currentColor" font-size="22">隐藏层</text>
    <text x={690} y={294} text-anchor="middle" fill="currentColor" font-size="22">输出层</text>
  </svg>
  <caption>这里只画出三层全连接关系。节点数量、层数和连线都可以由数据动态生成。</caption>
</card>
