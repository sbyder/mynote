## 池化层

池化层把局部区域压缩成一个数。以四个数 $1, 2, 3, 4$ 为例：

| 方法 | 输出 |
| --- | ---: |
| 最大池化 | 4 |
| 平均池化 | 2.5 |

```python
window = [1, 2, 3, 4]
maximum = max(window)
average = sum(window) / len(window)
```

## DIL 卷积实验：窗口怎么滑动

调节参数，再拖动「窗口位置」，观察卷积核沿填充后网格的第一行的有效位置移动。这里假设输入和卷积核均为正方形，膨胀率为 1。

{@body
  const [width, setWidth] = DIL.useState(16);
  const [kernel, setKernel] = DIL.useState(3);
  const [stride, setStride] = DIL.useState(2);
  const [padding, setPadding] = DIL.useState(1);
  const [step, setStep] = DIL.useState(0);
  const dark = DIL.useTheme() === "dark";

  const size = width + 2 * padding;
  const output = size >= kernel ? Math.floor((size - kernel) / stride) + 1 : 0;
  const position = Math.min(step, Math.max(output - 1, 0));
  const scale = Math.min(24, 232 / size);
  const extent = size * scale;
  const x = (288 - extent) / 2;
  const y = 22;
  const grid = Array.from({ length: size + 1 }, (_, i) => i * scale);
  const palette = dark
    ? { pad: "#2c3a4b", input: "#1f554b", grid: "#519084", window: "#fbc778", ink: "#e1e9e4" }
    : { pad: "#e7edf5", input: "#d5eee5", grid: "#83b4a8", window: "#ae5b24", ink: "#304a42" };
  const reset = () => {
    setWidth(16);
    setKernel(3);
    setStride(2);
    setPadding(1);
    setStep(0);
  };
}

<card padding={4} gap={3}>
  <row align="center" justify="between" wrap gap={2}>
    <title>二维卷积 · 输出尺寸</title>
    <badge label={output ? "输出 " + output + " × " + output : "无有效窗口"} />
  </row>
  <divider />
  <row gap={4} wrap align="center">
    <col flex="1 1 270px" minWidth={0} gap={2}>
      <svg viewBox="0 0 288 272" width="100%" role="img" aria-label="卷积窗口在填充后的输入网格中的位置">
        <rect x={x} y={y} width={extent} height={extent} rx={2} fill={palette.pad} />
        <rect x={x + padding * scale} y={y + padding * scale} width={width * scale} height={width * scale} fill={palette.input} />
        {grid.map((offset, i) => <g key={i} stroke={palette.grid} stroke-opacity={0.65} stroke-width={0.6}>
          <line x1={x + offset} y1={y} x2={x + offset} y2={y + extent} />
          <line x1={x} y1={y + offset} x2={x + extent} y2={y + offset} />
        </g>)}
        {output > 0 && <rect
          x={x + position * stride * scale}
          y={y}
          width={kernel * scale}
          height={kernel * scale}
          fill={palette.window}
          fill-opacity={0.24}
          stroke={palette.window}
          stroke-width={2.5}
          rx={1}
        />}
      </svg>
      <caption>绿色是输入，蓝灰色是填充，橙框是当前卷积窗口。</caption>
    </col>

    <col flex="1 1 245px" minWidth={0} gap={2}>
      <text>输入宽度 N · {width}</text>
      <slider min={1} max={32} value={width} onChange={setWidth} aria-label="输入宽度" />
      <text>卷积核 K · {kernel}</text>
      <slider min={1} max={9} value={kernel} onChange={setKernel} aria-label="卷积核大小" />
      <text>步幅 S · {stride}</text>
      <slider min={1} max={5} value={stride} onChange={setStride} aria-label="步幅" />
      <text>填充 P · {padding}</text>
      <slider min={0} max={5} value={padding} onChange={setPadding} aria-label="填充" />
      <text>窗口位置 · {output ? (position + 1) + " / " + output : "—"}</text>
      <slider min={0} max={Math.max(1, output - 1)} value={position} onChange={setStep} disabled={output < 2} aria-label="窗口位置" />
    </col>
  </row>
  <divider />
  <row align="center" justify="between" wrap gap={2}>
    <text role="status">{output
      ? "⌊(" + width + " + 2 × " + padding + " − " + kernel + ") ÷ " + stride + "⌋ + 1 = " + output
      : "填充后的输入比卷积核小，无法放置窗口。"}</text>
    <button onClick={reset}>重置参数</button>
  </row>
</card>
