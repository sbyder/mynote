## 池化层

池化层把局部区域压缩成一个数。以四个数 $1, 2, 3, 4$ 为例：

| 方法 | 输出 |
| --- | ---: |
| 最大池化 | 4 |
| 平均池化 | 2.5 |

```python
window = [1, 2, 3, 4]
maximum = max(window)
average = sum(window) / len(window)
```

## HTML 交互示例：卷积输出尺寸

调整参数，观察卷积的输出宽度。这个示例使用 `html-demo` 代码块，可以点「编辑源码」查看写法。

```html-demo
<!doctype html>
<html lang="zh-CN">
<style>
  :root { color-scheme: light dark; font: 15px system-ui; }
  body { max-width: 44rem; margin: 1.4rem auto; padding: 0 1.3rem; }
  form { display: grid; grid-template-columns: repeat(auto-fit, minmax(11rem, 1fr)); gap: .9rem 1.2rem; }
  label { display: grid; gap: .4rem; }
  input { width: 100%; margin: 0; accent-color: #517b68; }
  p { line-height: 1.6; }
  output { font-weight: 750; }
</style>
<body>
<h2>卷积输出尺寸</h2>
<form>
  <label>输入宽度 <input data-key="n" type="range" min="1" max="32" value="16"></label>
  <label>卷积核宽度 <input data-key="k" type="range" min="1" max="9" value="3"></label>
  <label>步幅 <input data-key="s" type="range" min="1" max="5" value="1"></label>
  <label>两侧填充 <input data-key="p" type="range" min="0" max="5" value="1"></label>
</form>
<p id="calculation"></p>
<p>输出宽度 <output id="result" aria-live="polite"></output></p>
<script>
  const form = document.querySelector('form');
  const result = document.querySelector('#result');
  const calculation = document.querySelector('#calculation');
  function update() {
    const { n, k, s, p } = Object.fromEntries([...form.querySelectorAll('input')].map(
      input => [input.dataset.key, Number(input.value)]
    ));
    const width = Math.floor((n + 2 * p - k) / s) + 1;
    calculation.textContent = '⌊(' + n + ' + 2 × ' + p + ' − ' + k + ') ÷ ' + s + '⌋ + 1';
    result.textContent = n + 2 * p >= k ? width : '卷积核比填充后的输入宽';
  }
  form.addEventListener('input', update);
  update();
</script>
</body>
</html>
```
