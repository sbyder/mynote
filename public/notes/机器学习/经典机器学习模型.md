# 经典机器学习模型

> 返回总纲：[机器学习知识库.md](./机器学习知识库.md)

经典机器学习模型不是深度学习之前已经过时的东西。它们至今仍广泛用于表格数据、业务预测、分类、聚类和基线实验。

学习这些模型的目的，是理解不同模型如何表达规律，以及为什么不同数据适合不同方法。

# 2. 线性回归（Linear Regression）

用于预测连续数值。

最简单的形式：

$$
\hat y=wx+b
$$

多特征形式：

$$
\hat y=\mathbf{w}^T\mathbf{x}+b
$$

训练时可以使用 MSE：

$$
L=\frac{1}{N}\sum_{i=1}^{N}(\hat y_i-y_i)^2
$$

## 它能表达什么

线性回归在原始特征空间中表达线性关系。

如果真实关系明显弯曲或存在复杂交互，单纯线性模型可能欠拟合。

但可以通过特征变换增加表达能力，例如加入 $x^2$、$x_1x_2$ 等特征。此时模型对新特征仍然是线性的。

它是理解模型、参数、损失函数和梯度下降的简单入口，也经常作为回归任务的基线模型。

---

# 3. 逻辑回归（Logistic Regression）

虽然名字里有回归，但它主要用于分类。

先计算线性分数：

$$
z=\mathbf{w}^T\mathbf{x}+b
$$

二分类时通过 Sigmoid 转成概率：

$$
p(y=1\mid x)=\sigma(z)=\frac{1}{1+e^{-z}}
$$

再根据阈值作出分类决策。

默认阈值常取 0.5，但实际可以根据误判成本和业务需求调整。

## 决策边界

当 $p(y=1\mid x)=0.5$ 时：

$$
\mathbf{w}^T\mathbf{x}+b=0
$$

这是一个线性决策边界。

多分类可以使用 Softmax Regression，将分数转换为多个类别的概率。

逻辑回归虽然输出概率，但其决策边界在原始特征空间中仍是线性的。它是非常重要的分类基线模型。

# 4. K 近邻（K-Nearest Neighbors, KNN）

KNN 的核心思想：

> 一个样本属于什么类别，可以参考它附近最相似的样本。

流程：

1. 保存训练样本。
2. 对新样本计算与训练样本的距离。
3. 找出距离最近的 $k$ 个样本。
4. 分类时投票，回归时可以取均值或加权均值。

关键超参数：

- $k$：邻居数量
- 距离度量：欧氏距离、曼哈顿距离等
- 是否按距离加权

特点：

- 训练阶段通常几乎不需要拟合参数
- 预测阶段需要比较新样本与训练样本
- 对特征尺度和距离定义敏感
- 高维空间中距离可能变得不那么有区分力

KNN 是典型的基于实例的学习方法。

# 5. 朴素贝叶斯（Naive Bayes）

基于贝叶斯定理：

$$
P(y\mid x)=\frac{P(x\mid y)P(y)}{P(x)}
$$

朴素贝叶斯作出一个简化假设：

> 给定类别后，各个特征条件独立。

于是：

$$
P(x_1,\ldots,x_n\mid y)
\approx
\prod_iP(x_i\mid y)
$$

它可以根据各类别的后验概率进行分类。

特点：

- 训练和预测通常很快
- 对高维稀疏文本特征常有不错的表现
- 条件独立假设在现实中通常不完全成立

它的价值不在于假设永远正确，而在于用简单假设换取较低的计算成本。

# 6. 决策树（Decision Tree）

决策树通过一系列特征判断逐步划分数据：

~~~text
年龄 < 30？
├── 是：收入 < 某阈值？
│   ├── 是：类别 A
│   └── 否：类别 B
└── 否：类别 C
~~~

训练时，算法选择能够让数据划分得更好的特征和阈值。

常见划分指标：

- Gini Impurity
- Entropy / Information Gain
- 回归树中的方差或平方误差下降

特点：

- 能表达非线性决策边界
- 能自然处理特征之间的非线性交互
- 对特征缩放通常不敏感
- 树太深时容易过拟合

常见限制：

- 最大深度
- 叶节点最小样本数
- 分裂所需的最小样本数
- 剪枝策略

# 7. 集成学习（Ensemble Learning）

集成学习是组合多个模型的思想。

## 7.1 Bagging

通过不同训练样本子集训练多个模型，再组合预测。

典型例子：Random Forest。

## 7.2 随机森林（Random Forest）

训练多棵决策树：

- 每棵树使用随机抽样得到的数据
- 每次分裂时随机选择部分特征
- 分类通常投票，回归通常取平均

目标是降低单棵树对训练数据波动的敏感性。

## 7.3 Boosting

模型按顺序训练，后续模型重点改善当前集成模型的不足。

典型方法：

- AdaBoost
- Gradient Boosting
- XGBoost
- LightGBM
- CatBoost

Boosting 通常在表格数据任务中非常强，是神经网络之外值得优先了解的一大类方法。

## Bagging 与 Boosting

| 对比 | Bagging | Boosting |
|---|---|---|
| 模型训练 | 通常可并行 | 通常按阶段依赖前序结果 |
| 主要目标 | 降低方差 | 逐步改善预测误差 |
| 代表 | Random Forest | XGBoost、LightGBM |

# 8. 支持向量机（SVM）

SVM 的核心思想是寻找能够区分类别的决策边界，并尽量扩大分类间隔（Margin）。

在线性可分的简化情况下，模型希望找到一个超平面：

$$
\mathbf{w}^T\mathbf{x}+b=0
$$

对于复杂的非线性边界，可以使用 Kernel Trick：

> 不显式构造高维特征，而通过核函数计算高维空间中的相似度。

常见核函数：

- Linear Kernel
- Polynomial Kernel
- RBF Kernel

SVM 对特征尺度、正则化强度和核参数较敏感。

# 9. 无监督学习

## 9.1 K-means

将样本分成 $K$ 个簇，尽量让每个样本靠近所属簇的中心：

$$
L=\sum_i\|x_i-\mu_{c_i}\|^2
$$

迭代过程：

1. 初始化 $K$ 个中心。
2. 把每个样本分配给最近中心。
3. 根据分配结果重新计算中心。
4. 重复直到收敛或达到停止条件。

需要提前指定 $K$，并且对特征尺度和初始化有一定敏感性。

## 9.2 PCA（Principal Component Analysis）

主成分分析用于降维。

它寻找一组新的正交方向，使数据投影到这些方向后，前几个方向尽可能保留较大的方差。

用途：

- 降低特征维度
- 压缩数据
- 可视化
- 去除部分冗余信息

PCA 是线性降维方法，不保证保留与预测任务最相关的信息。

# 10. 如何理解不同模型的区别

| 模型 | 核心机制 | 常见适用场景 |
|---|---|---|
| 线性回归 | 线性函数拟合 | 连续值预测、基线 |
| 逻辑回归 | 线性分数 + 概率映射 | 分类基线 |
| KNN | 邻近样本投票 | 小规模、距离有意义的数据 |
| 朴素贝叶斯 | 条件概率与独立假设 | 文本分类等 |
| 决策树 | 递归规则划分 | 非线性、可解释规则 |
| 随机森林 | 多树 Bagging | 稳健的表格数据基线 |
| Boosting | 顺序集成 | 高性能表格数据建模 |
| SVM | 最大间隔与核方法 | 中小规模分类 |
| K-means | 距离与簇中心 | 聚类 |
| PCA | 最大方差方向 | 线性降维 |

没有一个模型在所有任务上都最好。选择模型需要考虑数据规模、特征类型、计算资源、解释性、训练成本和验证表现。

---

# 11. 与神经网络的联系

神经网络并不是与经典模型完全无关的另一套东西。

- 线性层本质上执行仿射变换。
- 逻辑回归可以看成带 Sigmoid 输出的简单模型。
- 多层感知机通过多层线性变换和非线性激活，构建更复杂的函数。
- CNN 利用图像的局部连接和权重共享。
- Transformer 利用注意力机制处理序列或其他 token 之间的关系。

学习经典模型，可以帮助理解神经网络究竟增加了什么表达能力和归纳偏置。

# 12. 建议学习顺序

1. 线性回归
2. 逻辑回归
3. 决策树
4. 随机森林与 Boosting
5. KNN 与朴素贝叶斯
6. SVM
7. K-means 与 PCA

不必在每个算法上投入相同深度。优先理解模型假设、表达能力、损失或目标函数，以及它们的优缺点。
