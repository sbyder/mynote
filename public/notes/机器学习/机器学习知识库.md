# 2. 机器学习的核心主线

~~~text
问题
↓
数据
↓
选择模型
↓
定义训练目标与损失
↓
训练参数
↓
验证效果
↓
调整模型 / 超参数 / 数据
↓
测试泛化能力
~~~

本质上是在学习一个函数：

$$
y=f(x;\theta)
$$

其中：

- $x$：输入
- $y$：输出
- $\theta$：模型参数

训练的目标，是找到一组参数，使模型从数据中学到规律，并且在没见过的数据上仍然表现良好。

> **真正目标不是把训练集拟合到极致，而是泛化。**

# 3. 基础概念

## 3.1 数据、特征与标签

- **样本**：一个数据实例
- **特征**：描述样本的输入变量
- **标签 / Target**：训练时希望模型预测或重建的目标

例如房价预测：

~~~text
面积、楼层、位置、房龄 → 特征
房价 → 目标
~~~

目标可以来自人工标注、现实记录、传感器，也可以由数据本身构造。详见：[损失函数与监督信号.md](./损失函数与监督信号.md)。

## 3.2 参数与超参数

**参数**通过训练从数据中学习，例如神经网络权重和偏置。

**超参数**由训练者设定或通过搜索选择，例如：

- 学习率
- batch size
- 网络层数
- 每层神经元数
- 正则化强度
- 决策树最大深度

## 3.3 损失函数

Loss 把任务目标转化为可优化的数值。模型预测与目标比较后得到样本损失，再按训练方式汇总。

不同任务的目标形式不同，因此损失函数也不同。

详见：[损失函数与监督信号.md](./损失函数与监督信号.md)。

# 4. 学习范式

- **监督学习**：使用带目标的数据训练，例如分类和回归。
- **无监督学习**：没有人工标签，寻找数据结构，例如聚类和降维。
- **半监督学习**：少量有标签数据配合大量无标签数据。
- **自监督学习**：从数据自身构造训练目标。
- **强化学习**：通过状态、动作和奖励学习策略。

# 10. 应用领域

- **NLP**：文本分类、翻译、问答、文本生成、信息抽取
- **计算机视觉 CV**：图像分类、目标检测、图像分割、图像生成
- **语音**：识别、合成、说话人识别
- **推荐系统**：排序、召回、点击率预测
- **时间序列**：预测、异常检测
- **多模态**：联合处理文本、图像、音频等不同模态

应用领域与模型架构不是同一层级：一个领域可能使用多种架构，一种架构也可能服务于多个领域。
