# 1. 神经元与层

一个普通神经元先对输入做加权求和：

$$
z=\sum_{i=1}^{n}w_i x_i+b
$$

再经过激活函数：

$$
a=\sigma(z)
$$

可以理解为：

~~~text
输入
↓
加权求和
↓
激活函数
↓
输出
~~~

同一层中：

- 每个神经元通常有自己的一组权重和偏置
- 同一层的神经元通常使用相同类型的激活函数
- 参数不同，神经元就可以学习不同的特征

## 为什么需要非线性

如果连续堆叠线性层：

$$
h=W_1x+b_1
$$

$$
y=W_2h+b_2
$$

代入后仍然可以合并成：

$$
y=W'x+b'
$$

所以，没有非线性变换时，多层线性层仍然等价于一个线性变换。

激活函数让网络能够表达更复杂的非线性关系。

# 2. 激活函数

激活函数的作用是为网络引入非线性。下面先列出常见家族，具体性质和适用场景可以逐步补充。

| 激活函数 | 主要特点 |
|---|---|
| Sigmoid | 输出在 $(0,1)$；平滑；两端容易饱和 |
| Tanh | 输出在 $(-1,1)$；以 0 为中心；两端容易饱和 |
| ReLU | 正区间线性、负区间为 0；简单常用 |
| Leaky ReLU | 负区间保留小斜率 |
| PReLU | 负区间斜率可学习 |
| ELU | 负区间采用平滑的指数形式 |
| SELU | 为自归一化网络设计的特殊激活函数 |
| GELU | 平滑门控形式，常见于 Transformer |
| SiLU / Swish | $x\cdot\operatorname{sigmoid}(x)$，平滑且常用于现代网络 |
| Softplus | 平滑版本的 ReLU |
| Softmax | 将一组分数转换为概率分布，常用于多分类输出层 |

注意：Softmax 通常作用于一组输出，而不是像 ReLU 那样逐元素独立使用。

## 常见公式

### Sigmoid

$$
\sigma(x)=\frac{1}{1+e^{-x}}
$$

### Tanh

$$
\tanh(x)=\frac{e^x-e^{-x}}{e^x+e^{-x}}
$$

### ReLU

$$
\operatorname{ReLU}(x)=\max(0,x)
$$

### Leaky ReLU

$$
f(x)=
\begin{cases}
x,&x>0\\
\alpha x,&x\leq 0
\end{cases}
$$

### SiLU / Swish

$$
\operatorname{SiLU}(x)=x\sigma(x)
$$

激活函数没有脱离任务和网络结构的绝对排名。初始化、学习率、归一化方式等也会影响实际效果。

# 3. 参数初始化

参数初始化决定训练开始时，网络从什么状态出发。

## 3.1 为什么权重不能全部相同

如果同一层的多个神经元拥有完全相同的权重和偏置，那么它们接收相同输入后会产生相同输出、相同梯度和相同更新。

它们就无法分工学习不同特征。

因此，权重通常需要随机初始化，以打破神经元之间的对称性。

偏置则通常可以初始化为 0。

## 3.2 为什么不能随便设置随机范围

神经元计算：

$$
z=\sum_{i=1}^{n}w_i x_i+b
$$

如果权重尺度太大，信号经过多层后可能不断放大；如果太小，信号可能逐层衰减。

这会影响前向传播的激活值，也会影响反向传播的梯度。

初始化方法会根据输入规模、输出规模和激活函数选择合适的权重尺度。

## 3.3 Xavier / Glorot 初始化

常用于 Tanh 等近似对称的激活函数。

常见的目标方差：

$$
\operatorname{Var}(w)\approx\frac{2}{fan_{in}+fan_{out}}
$$

其中：

- $fan_{in}$：输入连接数量
- $fan_{out}$：输出连接数量

## 3.4 He 初始化

常用于 ReLU 及其变体。

典型目标方差：

$$
\operatorname{Var}(w)\approx\frac{2}{fan_{in}}
$$

它考虑了 ReLU 会将负半轴的响应置为 0 这一特点。

## 3.5 其他初始化

- LeCun Initialization
- Orthogonal Initialization
- Normal / Uniform Initialization
- Truncated Normal Initialization

经验起点：

- Tanh：常考虑 Xavier
- ReLU：常考虑 He

这不是不可更改的硬规则，具体还要看网络结构和实现。

## 3.6 随机种子

随机种子用于让随机数序列可复现，从而让初始化和实验更容易复现。

它不是一种初始化算法。

# 4. 网络宽度与深度

## 宽度

增加某一层的神经元数量，增加这一层能够并行表示的特征数量，也会增加参数量。

## 深度

增加网络层数，让特征经过更多次连续变换。

可以粗略记为：

- 宽度：同一层能表示多少种特征
- 深度：特征能经过多少级加工

更深或更宽不保证一定更好，还要考虑数据量、优化难度和过拟合。

# 5. 归一化层：BatchNorm 与 LayerNorm

归一化层通常放在网络内部，用来调整中间激活值的尺度。

一般形式是先标准化：

$$
\hat{x}=\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}
$$

再通过可学习参数恢复合适的缩放和平移：

$$
y=\gamma\hat{x}+\beta
$$

其中 $\gamma$ 和 $\beta$ 是可学习参数。

## 5.1 Batch Normalization（BatchNorm）

对一个特征（或 CNN 中的一个通道），跨 batch 中的样本统计均值和方差。

对于卷积特征图，通常还会在空间位置维度上一起统计。

特点：

- 依赖 batch 统计
- 训练时使用当前 batch 的统计量
- 推理时通常使用训练期间累计的 running mean 和 running variance
- batch 很小时，统计量可能不稳定

## 5.2 Layer Normalization（LayerNorm）

对单个样本内部的特征维度计算均值和方差。

在 Transformer 中，通常对每个 token 的隐藏特征维度进行归一化。

特点：

- 不依赖其他样本
- 对 batch size 不敏感
- 训练和推理时的计算方式基本一致
- 常见于 Transformer

## 5.3 两者的核心区别

~~~text
BatchNorm：
同一特征，跨样本统计

LayerNorm：
同一样本，跨特征统计
~~~

它们都包含可学习的缩放和平移参数，但统计范围不同。

# 6. 残差连接（Residual / Skip Connection）

残差连接让输入绕过若干层，直接与这些层的输出相加：

$$
y=F(x)+x
$$

它可以让网络学习相对于输入的变化量，而不必让这几层从头表示完整映射。

主要作用：

- 为信息提供直接传递路径
- 为梯度提供较短的回传路径
- 缓解深层网络训练中的优化困难

ResNet 是残差连接的标志性应用，详见：[卷积神经网络.md](./卷积神经网络.md#7-resnet与残差连接)。
