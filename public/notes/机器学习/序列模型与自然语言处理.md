## 1. 序列数据与语言建模

### 1.1 什么是序列

序列（Sequence）是具有顺序关系的一组数据。顺序本身通常携带信息，交换元素的位置可能改变含义。

常见序列数据：

- 文本：词语或 Token 的先后顺序
- 语音：声音信号随时间变化
- 时间序列：传感器、气象、金融等连续观测
- 视频：按时间排列的图像帧
- 行为记录：用户点击、购买等事件序列

与普通特征向量相比，序列模型需要处理元素之间的顺序、上下文和依赖关系。

### 1.2 语言模型（Language Model）

语言模型学习文本序列的概率规律。自回归语言模型通常把下一个 Token 的概率写成：

$$
P(x_1,\ldots,x_T)=\prod_{t=1}^{T}P(x_t\mid x_1,\ldots,x_{t-1})
$$

训练目标通常是：给定前面的 Token，预测下一个 Token。

例如：

~~~text
输入：今天 天气 很
目标：好
~~~

这可以从原始文本自动构造训练目标，不需要人工逐句标注语义，属于自监督学习。

## 2. Tokenization：文本如何变成离散输入

神经网络不能直接对字符串做矩阵运算。文本需要先切分成模型使用的基本单位，再映射为整数 ID。

### 2.1 Token 与 Token ID

Token 不一定等于完整单词。根据分词器（Tokenizer）的规则，一个词可能：

- 对应一个 Token
- 被拆成多个子词（Subword）
- 与标点、空格或其他字符组合成 Token

示意：

~~~text
原始文本
  ↓ Tokenizer
["机器", "学习", "很", "有趣"]
  ↓ 词表映射
[125, 832, 19, 406]
~~~

Token ID 只是词表中的索引，不具有可直接解释的语义大小关系。ID 相差 1 不代表两个 Token 更相似。

### 2.2 One-Hot Encoding

若词表大小为 $V$，Token 可以表示为长度为 $V$ 的独热向量，只有对应位置为 1，其余位置为 0。

问题：

- 维度随词表增大，向量非常稀疏
- 不同 Token 的 One-Hot 向量彼此正交，不直接表达语义相似性

因此通常会使用 Embedding 将离散 ID 映射为稠密向量。

## 3. 词嵌入（Word / Token Embedding）

### 3.1 Embedding 是可学习的查找表

假设词表有 $V$ 个 Token，每个 Token 使用 $d$ 维向量表示，则 Embedding 矩阵为：

$$
E\in\mathbb{R}^{V\times d}
$$

输入 Token ID 后，模型取出矩阵中对应的一行：

$$
e_i=E[i]
$$

也可以等价地写成 One-Hot 向量与矩阵相乘：

$$
e_i=\operatorname{onehot}(i)^\top E
$$

Embedding 矩阵通常是可训练参数，会通过反向传播更新。

### 3.2 分布式表示

一个 Token 的含义不是由某一个维度单独决定，而通常分布在多个维度的组合中。

训练后，出现在相似上下文中的词可能在向量空间中呈现相似关系。但各维度通常没有固定、直观的人类语义标签。

### 3.3 Word2Vec

Word2Vec 是经典的静态词向量学习方法，核心思想是利用上下文预测任务学习词向量。

- **CBOW**：根据周围上下文预测中心词。
- **Skip-gram**：根据中心词预测周围上下文。

模型并不需要人工写入“猫和狗都是动物”这样的规则；相似上下文会在训练中间接塑造相似表示。

### 3.4 静态嵌入与上下文化表示

传统 Word2Vec 通常为一个词保存固定向量，因此同一个词在不同句子中的初始表示相同。

例如：

- “我吃了一个苹果。”
- “苹果发布了新手机。”

这里的“苹果”含义不同，但静态词向量本身不会随句子变化。

上下文化模型会进一步结合上下文计算表示：

~~~text
Token Embedding
      ↓
上下文网络（RNN / Transformer）
      ↓
Contextual Representation
~~~

同一个 Token 在不同句子中，经过上下文网络后可以得到不同的隐藏表示。

现代语言模型通常以 Token 而非完整单词为基本单位，因此“Token Embedding”是更宽泛、准确的说法。

## 4. 循环神经网络（RNN）

### 4.1 核心思想：隐藏状态传递历史信息

RNN 按时间顺序处理序列。每一步接收当前输入和上一步的隐藏状态：

$$
h_t=f(W_xx_t+W_hh_{t-1}+b)
$$

其中：

- $x_t$：当前时间步的输入向量，文本任务中可以是 Token Embedding
- $h_{t-1}$：上一步隐藏状态
- $h_t$：当前隐藏状态
- $W_x,W_h,b$：训练得到的参数

同一组参数会在不同时间步重复使用，这叫参数共享。

### 4.2 为什么隐藏状态有用

隐藏状态让当前计算能够利用此前输入的信息：

~~~text
x₁ → RNN → h₁
             ↓
x₂ → RNN → h₂
             ↓
x₃ → RNN → h₃
             ↓
           ...
~~~

它并不是完整保存所有历史 Token，而是把历史信息压缩进固定维度的状态中。因此长距离依赖可能难以保留。

### 4.3 RNN 的训练：时间反向传播

RNN 在多个时间步重复使用同一组参数。计算损失后，梯度需要沿时间展开的计算图反向传播，这通常称为 BPTT（Backpropagation Through Time）。

长序列中的梯度可能出现消失或爆炸。LSTM 和 GRU 通过门控机制改善长期信息传递，但并不能保证所有长距离依赖都能完美保留。

### 4.4 LSTM 与 GRU

- **LSTM**：使用输入门、遗忘门、输出门和细胞状态，控制信息写入、保留和输出。
- **GRU**：使用更新门和重置门，结构相对简化。

它们都是为改善普通 RNN 的长期依赖和梯度传播问题而设计的循环网络变体。

## 5. Seq2Seq：序列到序列

Seq2Seq（Sequence-to-Sequence）描述一种输入序列映射到输出序列的任务形式。经典实现采用 Encoder–Decoder 结构。

典型应用：

- 机器翻译
- 文本摘要
- 对话回复生成
- 语音识别与转换

### 5.1 Encoder：编码输入

Encoder 逐步读取输入序列，得到隐藏状态：

$$
h_1,h_2,\ldots,h_{T_x}
$$

最简单的 RNN Seq2Seq 会把最后一个隐藏状态作为固定长度上下文向量：

$$
c=h_{T_x}
$$

### 5.2 Decoder：逐步生成输出

Decoder 根据上下文和已经生成的 Token，逐步预测下一个 Token：

$$
P(y_t\mid y_{<t},x)
$$

输出长度可以与输入长度不同。常见特殊 Token：

- <BOS>：序列开始
- <EOS>：序列结束

生成时，模型通常把上一步生成的 Token 作为下一步输入，直到输出 <EOS> 或达到长度限制。

### 5.3 Teacher Forcing

训练时可以把目标序列中正确的前一个 Token 输入 Decoder，而不是始终使用模型自己的预测。这叫 Teacher Forcing。

优点是训练初期更稳定、每一步都能获得正确的上下文输入。

局限是训练时看到正确历史，推理时却要依赖自己的预测，两者存在差异，可能产生 Exposure Bias（暴露偏差）。

### 5.4 固定上下文向量的信息瓶颈

如果无论输入多长，都只把一个固定维度向量交给 Decoder，那么长句中的细节可能难以完整保留。

这推动了 Attention 在 Seq2Seq 中的应用。

## 6. Attention：根据当前内容动态聚合信息

### 6.1 从固定上下文到动态读取

不带 Attention 的简单 Seq2Seq：

~~~text
Encoder 所有输入
      ↓
一个固定 Context Vector
      ↓
Decoder
~~~

加入 Attention 后，Decoder 在每个生成步骤都可以查看 Encoder 的多个隐藏状态：

~~~text
Encoder：h₁  h₂  h₃  ...  hₙ
           \   |   |       /
            当前 Decoder 状态
                    ↓
             计算注意力权重
                    ↓
             加权聚合 Encoder 信息
                    ↓
             当前 Context Vector
~~~

### 6.2 注意力权重如何计算

设 Decoder 当前状态为 $s_{t-1}$，Encoder 第 $i$ 个隐藏状态为 $h_i$。先计算匹配分数：

$$
e_{t,i}=\operatorname{score}(s_{t-1},h_i)
$$

再在输入位置上使用 Softmax：

$$
\alpha_{t,i}
=
\frac{\exp(e_{t,i})}
{\sum_j\exp(e_{t,j})}
$$

得到当前步骤对各输入位置的相对权重，再聚合：

$$
c_t=\sum_i\alpha_{t,i}h_i
$$

当输入和输出序列都固定时，可以把这些权重排成矩阵。矩阵的一行对应一个 Decoder 位置，一列对应一个 Encoder 位置。

### 6.3 Attention 不是固定连接矩阵

需要区分两类矩阵：

- 可训练投影参数：训练后固定，例如 $W_Q,W_K,W_V$。
- 注意力权重：根据当前输入和上下文计算，例如 $\alpha_{t,i}$。

因此，模型学到的是“如何计算注意力”的规则，而不是一张适用于所有句子的固定注意力表。

### 6.4 Attention 权重不等于绝对重要性

$\alpha_{t,i}$ 表示在当前 Query 的信息聚合中，各 Key 对应 Value 的相对权重。它通常经过 Softmax 归一化，且取决于当前查询。

它不等于：

- 这个词在整篇文章中的全局重要性
- 这个词对最终答案的因果贡献
- 人类阅读时应该关注它的程度

如果要判断某个信息对某个任务是否有价值，需要明确任务目标，并设计相应的评分和评估方式。

## 7. Transformer：以 Attention 为核心的序列架构

Transformer 由论文 *Attention Is All You Need*（2017）提出。它不依赖 RNN 的逐时间步隐藏状态传递，而是使用 Attention 让序列位置之间直接交换信息。

### 7.1 Self-Attention

Self-Attention 中，Query、Key、Value 来自同一组输入表示：

$$
Q=XW_Q,\quad K=XW_K,\quad V=XW_V
$$

缩放点积注意力：

$$
\operatorname{Attention}(Q,K,V)
=
\operatorname{softmax}
\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

其中：

- Query：当前位置要寻找什么信息
- Key：各位置提供用于匹配的表示
- Value：各位置实际提供的信息
- $QK^\top$：计算位置之间的匹配分数
- Softmax：将分数转成归一化权重

### 7.2 Self-Attention 与 Cross-Attention

| 类型 | Query 来源 | Key / Value 来源 | 作用 |
|---|---|---|---|
| Self-Attention | 当前序列 | 当前序列 | 序列内部信息交互 |
| Cross-Attention | 一个序列 | 另一个序列 | 一个序列读取另一个序列的信息 |

例如 Encoder–Decoder Transformer 中：

- Encoder 内部使用 Self-Attention。
- Decoder 内部使用带因果掩码的 Self-Attention。
- Decoder 还可以通过 Cross-Attention 读取 Encoder 输出。

### 7.3 Multi-Head Attention

多头注意力使用多组不同的投影，让模型从不同表示子空间计算注意力，再合并结果。

它不是简单地把同一张注意力矩阵复制多份，而是让不同头学习不同的投影和信息交互模式。

### 7.4 为什么需要位置编码

Attention 本身不会自动知道 Token 的先后顺序。若不提供位置信息，标准 Self-Attention 对输入 Token 的排列具有置换等变性。

因此 Transformer 需要加入位置编码或其他位置表示，让模型能够利用顺序信息。

### 7.5 Transformer 的其他组成

一个常见 Transformer Block 还包含：

- 残差连接（Residual Connection）
- LayerNorm
- 前馈网络（Feed Forward Network, FFN）
- Dropout（视模型配置而定）

Attention 负责位置之间的信息交互，FFN 对每个位置的特征进一步做非线性变换。两者分工不同。

### 7.6 因果掩码（Causal Mask）

自回归生成时，当前位置不能读取未来 Token。Causal Mask 会屏蔽未来位置，避免训练时偷看答案。

### 7.7 Transformer 的计算特点

标准全局 Self-Attention 的注意力矩阵大小与序列长度的平方相关，序列很长时，显存和计算开销会明显增加。稀疏注意力、局部注意力、线性注意力等方法尝试改善长序列成本。

## 8. 预训练语言模型的典型路线

### 8.1 Masked Language Modeling（MLM）

以 BERT 为代表。训练时遮挡部分 Token，让模型根据上下文预测被遮挡内容。

~~~text
输入：我 喜欢 [MASK] 学习
目标：机器
~~~

这是一种双向上下文学习方式。BERT 预训练的是包含 Attention、FFN 等组件的 Transformer Encoder，而不是单独训练 Attention。

### 8.2 Causal Language Modeling（CLM）

以 GPT 类 Decoder-only 模型为代表。模型根据左侧上下文预测下一个 Token：

~~~text
输入：我 喜欢 机器
目标：学习
~~~

通过逐步预测下一个 Token，模型可以在推理时自回归生成文本。

### 8.3 Encoder–Decoder 预训练

T5 等模型采用 Encoder–Decoder Transformer，把不同文本任务统一为输入文本到输出文本的转换。

### 8.4 预训练与迁移学习

预训练模型从大量数据中学习通用表示，再通过微调、任务头、Adapter 等方式迁移到下游任务。

迁移时不仅要考虑网络维度，还要考虑输入表示、归一化、训练目标和数据分布是否兼容。

## 9. RNN、Seq2Seq 与 Transformer 的关系

| 维度 | RNN | RNN Seq2Seq + Attention | Transformer |
|---|---|---|---|
| 信息传递 | 隐藏状态逐步传递 | Encoder 状态 + 动态读取 | Attention 直接交互 |
| 顺序处理 | 依赖时间步 | 依赖时间步 | 训练时可并行处理位置 |
| 长距离关系 | 可能难以保留 | 可通过 Attention 读取远处状态 | 可直接建立远距离注意力 |
| 常见任务 | 序列预测 | 翻译、摘要 | NLP、多模态等 |

Transformer 不是“凭空替代 RNN”，它承接了词嵌入、序列建模、Seq2Seq 和 Attention 等研究路线。
