# 研究构想与开放问题

> 返回总纲：[机器学习知识库.md](./机器学习知识库.md)

本分册不是机器学习主线教材，而是保存学习过程中形成的研究构想、待验证假设和可能的实验方向。这里记录的是问题与思路，不代表相关方法已经被证明可行。

---

## 1. 通用信息重要性评估模型

### 1.1 核心设想

能否训练一个独立的信息评估模型，输入内容、上下文和任务目标，输出不同信息单元的重要性分数？

它不负责生成答案或完成全部下游任务，而是回答：

- 哪些信息值得关注？
- 哪些部分与当前任务更相关？
- 哪些信息值得分配更多计算资源？
- 哪些内容可以降低处理优先级？

可以把目标抽象为：

$$
s_i=f_\theta(x_i,C,T)
$$

其中：

- $x_i$：待评估的信息单元，例如文档片段、视频帧、图像区域
- $C$：上下文
- $T$：当前任务或目标
- $s_i$：该信息单元相对于当前任务的重要性分数
- $\theta$：通过训练学习的参数

分数可以用于排序、筛选、加权或计算资源分配，不一定必须归一化为概率。

### 1.2 与 Attention 的区别

Attention 权重与重要性评分相关，但不能直接等同。

Attention 中的权重通常表示：在某个 Query 更新表示时，各 Key 对应 Value 的相对聚合权重。

$$
\alpha_{ij}
=
\operatorname{softmax}_j
\left(\operatorname{score}(q_i,k_j)\right)
$$

它具有以下特点：

- 与当前 Query 有关
- 通常在允许关注的位置上归一化
- 描述一次信息聚合时的相对权重
- 不一定等于信息对最终任务的因果贡献

任务条件化的重要性评分则试图评估某个信息单元对特定目标的价值。

因此，研究目标不应简单表述为“训练一个更大的 Attention”，而可以表述为“学习可迁移、任务条件化的信息价值评估能力”。

### 1.3 潜在应用

#### RAG：检索结果重排

~~~text
用户问题
   ↓
向量检索召回候选文档
   ↓
重要性 / 相关性评估模型
   ↓
候选文档打分与重排
   ↓
选择内容用于回答或展示
~~~

重排不一定需要生成式大模型。小型 Cross-Encoder 或其他判别式模型也能对问题与候选文档进行联合编码和打分。

潜在研究问题：

- 能否用一套模型适配不同领域和任务？
- 能否区分“语义相似”与“对当前问题真正有用”？
- 能否把文档级评分细化为段落、句子或事实级评分？

#### 视频理解：帧与区域的重要性

可以同时对时间维度和空间维度评分：

- 帧级评分：哪些时间点值得保留？
- 区域级评分：当前帧的哪些区域值得高分辨率处理？
- 事件级评分：哪些片段包含对任务有用的动作或状态变化？

这可能用于自适应采样和计算分配：

~~~text
视频
 ↓
候选帧与图像区域
 ↓
重要性评分
 ├── 低分：降低采样率或分辨率
 └── 高分：保留、放大或进一步分析
~~~

画面变化大不一定代表语义重要；静止画面中的关键物体也可能非常重要。因此评分最好结合任务目标，而不只依赖运动幅度或视觉变化。

SlowFast 等已有架构使用固定的快慢时间采样率分配计算预算。可以探索进一步扩展为**根据当前视频内容与任务动态调整帧率、分辨率和时空 Attention 范围**。这属于有待验证的研究设想，而非已实现结果。背景见：[视频理解与时空建模.md](./视频理解与时空建模.md)。

#### 图像生成：视觉层级与细节预算

图像生成可能出现细节丰富却缺乏视觉焦点的问题。

一种设想是预测空间重要性图，再将它用于生成过程：

- 主体或关键物体：分配更高的细节预算
- 次要区域：保持必要结构，减少无意义的细节
- 背景：根据构图目标控制复杂度

但重要性图本身不会自动保证画面好看。还需要研究如何把评分真正转化为生成约束，例如区域条件、空间损失、局部采样或生成过程中的计算分配。

### 1.4 可能的训练思路

可以组合多种训练信号：

| 训练方式 | 可能学习的能力 |
|---|---|
| 遮挡预测、信息恢复 | 上下文结构与信息关联 |
| 问题—段落相关性排序 | 任务条件化的文本价值 |
| 帧排序、事件定位 | 时间维度的重要性 |
| 区域显著性或区域任务反馈 | 空间维度的重要性 |
| 删除信息后的性能变化 | 信息对下游任务的实际贡献 |
| 成对偏好或排序标签 | 相对重要性判断 |

其中，删除某个信息后观察下游性能变化，是一种有价值的评估思路，但它不等于严格的因果证明。不同信息可能存在冗余、互补和上下文依赖。

### 1.5 可能的架构

一种待验证的方案是“模态适配器 + 共享评估核心”：

~~~text
任务 / 问题编码
       ↓
文本 / 图像 / 视频编码器
       ↓
统一或对齐的信息表示
       ↓
共享重要性评估网络
       ↓
Token / Region / Frame 分数
       ↓
下游系统排序、筛选或分配计算资源
~~~

不必强求文本、图像和视频共用同一个底层编码器。它们的数据结构不同，可以先由各自的编码器得到表示，再研究共享评估能力能否迁移。

### 1.6 主要难点

- **重要性依赖任务**：没有任务目标时，很难定义唯一正确的分数。
- **冗余与互补**：某个信息单独看似不重要，可能与其他信息组合后才有价值。
- **分数可比性**：不同模态、不同任务的分数未必处于同一尺度。
- **评估成本**：删除信息并重新运行大型下游模型可能很昂贵。
- **注意力解释问题**：模型内部 Attention 权重不能直接当作可靠的重要性标签。
- **迁移兼容性**：共享模块需要面对不同模态表示空间和下游接口。
- **先筛选再理解的计算成本**：判断帧是否重要本身需要计算，筛选器太昂贵可能抵消下游节省的算力。

### 1.7 可验证的起步实验

不要一开始就做跨模态通用模型。可以先选一个边界清晰的任务：

1. 选择一个公开的 RAG 或文档问答数据集。
2. 使用已有检索器召回候选段落。
3. 训练一个小型评分模型，对候选段落排序。
4. 与 BM25、向量相似度和普通 Reranker 比较。
5. 再把评分模型迁移到不同领域或不同问题类型。
6. 观察迁移后性能是否保持。

如果能证明一套评分能力在不同任务中具有稳定迁移性，再逐步扩展到视频和图像。

视频方向的另一种最小实验是：固定相同视频与下游分类器，比较均匀采样、SlowFast 式固定多频率采样和轻量评分器的动态采样。除了准确率，还应记录评分器本身的 FLOPs、实际延迟、总显存和关键短事件的召回率。先评估任务收益是否足以覆盖选择成本。

## 2. 以泛化能力为目标的数据生成

### 2.1 核心设想

普通合成数据通常希望生成内容接近真实数据分布。

另一种思路是：不把“像真实数据”作为唯一目标，而是关注这些合成数据能否帮助下游模型获得更好的泛化能力。

可以抽象为：

$$
\max_{\phi}
\operatorname{Generalization}
\left(
\operatorname{Train}(M,D_{\text{real}}\cup G_\phi)
\right)
$$

其中 $G_\phi$ 是由生成模型产生的数据，$M$ 是下游模型。

### 2.2 值得研究的问题

- 哪些合成样本能补足真实数据中的覆盖盲点？
- 是否应该重点生成模型容易出错的边界样本？
- 合成数据是否会引入与真实任务不一致的伪规律？
- 如何避免生成模型和下游模型相互强化错误？
- 如何用验证集反馈优化生成策略，同时避免对验证集过拟合？

这与数据增强、主动学习、数据估值、课程学习和数据集蒸馏等方向有关。

## 3. 根据数据集特征预测超参数

### 3.1 核心设想

收集大量已经完成的训练实验：

- 数据集特征
- 模型结构
- 超参数配置
- 训练成本
- 验证集表现

再训练一个元模型，学习数据集特征与较优超参数之间的关系。

~~~text
历史训练实验
├── 数据集特征
├── 模型配置
├── 超参数
└── 验证表现
       ↓
   元学习 / 性能预测模型
       ↓
输入新数据集特征
       ↓
推荐候选超参数
       ↓
少量真实实验验证
~~~

这与 Meta-learning、Learning to Optimize、算法配置和超参数性能预测等方向有关。

### 3.2 关键限制

- 数据集特征需要有足够代表性。
- 历史实验必须记录完整且可比较。
- 不同模型、训练预算和硬件环境可能造成分布差异。
- 推荐结果应作为搜索起点，而不是未经验证的最优答案。

## 4. 视频自监督学习与具身感知

### 4.1 从帧规律到语义

只有视频而没有人工语义标注，模型仍然可以学习：

- 相邻帧之间的变化
- 运动和时序规律
- 遮挡、连续性和物体状态变化
- 对未来帧或被遮挡区域的预测

但这些训练目标不自动保证模型掌握人类语义概念。模型可能学到有用的视觉规律，却不知道某个动作在人类任务中意味着什么。

### 4.2 多模态传感器与交互

一个拥有视觉、听觉、触觉等传感器的系统，可以在与环境交互时积累数据。

潜在学习目标包括：

- 预测动作之后的感官变化
- 建立物体与动作之间的关系
- 学习物体持续性和空间关系
- 通过预测误差发现环境规律

关键问题是：仅仅被动采集数据是否足够，还是需要主动探索、动作反馈、任务目标或其他形式的语义对齐？

这与自监督学习、世界模型、具身智能和主动感知有关。

## 5. 研究方向之间的联系

~~~text
数据与泛化
├── 合成数据优化
├── 数据估值
└── 主动学习

模型与训练
├── 超参数性能预测
├── Meta-learning
└── Learning to Optimize

信息处理
├── 通用重要性评估
├── 自适应计算分配
└── 主动感知

多模态与世界建模
├── 视频自监督学习
├── 时空信息选择
└── 具身感知
~~~

这些方向可以互相联系，但不必强行合并成一个模型。应先分别定义问题、建立基线、设计可验证实验，再判断是否存在可共享的核心能力。

## 6. 维护原则

1. 本分册保存构想，不替代机器学习主线教材。
2. 区分已有成熟方法、合理推测和个人提出的待验证假设。
3. 新想法先写清输入、输出、训练信号、评价指标和基线。
4. 不因概念相似就认定两个方向是同一个问题。
5. 优先寻找可低成本验证的最小实验。
